# Tasks

Verification follows the project rule: every task is verified by automated tests (unit tests, or Playwright on headless Chromium). Teachers' real sheets are never committed: tests use synthetic fixture sheets generated by a script, one per layout family, and an optional local folder of real sheets read from an environment variable. Checks that need the owner are marked "Optional manual check".

Every model stage is built and tested against stub models first. Tasks marked "Needs a model key" are run locally by the owner, because no key is available in the cloud session.
