# Bicho.exe design boards (reference sources)

Exported from the Claude Design canvas "Spanish Tutor Design Directions" (https://claude.ai/artifact/QjrqQFpwFQYAVfxJMDSQ2j, version 1793565160-d6d0, captured 2026-11-01). The design was made with Dolores.

These are Design Component sources (`.dc.html`). They need the Claude Design runtime (`support.js`) to render, so open the canvas link to see them. In the repo they are a readable record of colours, copy, layout and mechanics. Do not import them into the app.

Photos used in the collage are referenced as `/_blob/...` assets inside the canvas and are **not** copied here. Their provenance is unrecorded. Before any photo ships, log it in `docs/asset-credits.md` (source, licence, attribution if required).

## What each board is for in v1

| File | Use in v1 |
|---|---|
| `h-bicho-brand.dc.html` | **Active reference.** Palette, materials, type, logo, weirdness levels. |
| `collage.dc.html`, `fx.dc.html`, `sun.dc.html` | **Active reference.** Wallpaper collage, camcorder overlay, the watching sun (countdown). |
| `h-bicho-screens.dc.html` | **Active reference.** Home (Examen.exe, Pregunta files), Tutor.exe speaking screen, rewards. Ignore the pet meters. |
| `h-bicho-photos.dc.html` | **Active reference.** Photo brief and the slots still missing. |
| `h-bicho-play.dc.html` | **Partial.** Desktop shell feel only. |
| `bicho.dc.html`, `h-bicho-sheet.dc.html` | **Parked.** Bicho creature and model sheet. Tele is the v1 character. |
| `h-bicho-mechanics.dc.html` | **Parked.** Pet care loop (Comer, Jugar, Dormir, Limpiar, Crecer). The evolution idea may return later. |
| `h-bicho-games.dc.html` | **Parked.** Parejas, Arma la frase, Lluvia de palabras. |
| `h-bicho-tools.dc.html` | **Parked.** Apuntes (notes) and Garabatos (doodle pad). |
| `canvas.json` | Canvas index (board positions). |

See `docs/design-conflicts.md` for the decisions behind this split.
