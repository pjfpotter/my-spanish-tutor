# Asset credits

Every image under `public/` is logged here before it ships (task 18.7). A test (`lib/docs/asset-credits.test.ts`) fails if an image file has no row.

## Rules

- Only use images you took, hold a licence for, or that are CC0 or public domain. CC-BY needs attribution shown in the app. CC-BY-SA needs share-alike, so avoid it.
- No brand logos, no recognisable people, no children, and no look-alikes of commercial virtual-pet toys.
- AI-generated images are fine for abstract or moody shots, but not for recognisable real hardware.
- Record where it came from, the licence, whether attribution is required, and who checked it.

## Sources worth trying for old tech (from `docs/art-pipeline.md`)

Wikimedia Commons, Smithsonian Open Access, Library of Congress, The Met Open Access, Internet Archive, Flickr Commons, Rawpixel public domain, and Unsplash, Pexels and Pixabay.
